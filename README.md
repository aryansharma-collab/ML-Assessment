## Task 1: Hugging Face API

Follows the `freznelai` user and downloads 2 models using the HF Python API (no CLI).

```bash
export HF_TOKEN="hf_your_token_here"
python task1_hf.py
```

**What it does:**
1. Authenticates with Hugging Face using `HF_TOKEN`
2. Follows [freznelai](https://huggingface.co/freznelai) via `HfApi.follow_user()`
3. Downloads `FreznelAI_1.0_Face-Detector_500M_FZFP4_FRZm` via `snapshot_download()`
4. Downloads `FreznelAI_1.0_Face-Landmarker_500M_FZFP4_FRZm` via `snapshot_download()`

## Task 2: Data Scraping

Scrapes the first 100 PICO-8 games from the [Lexaloffle BBS](https://www.lexaloffle.com/bbs/?cat=7&carts_tab=1&#sub=2&mode=carts).

```bash
python task2_scraper.py
```

**Output:** `pico8_games.csv` with 8 columns:
| # | Field | Description |
|---|-------|-------------|
| 1 | `name` | Name of the game |
| 2 | `author` | Name of the author |
| 3 | `artwork_url` | URL to game artwork/thumbnail |
| 4 | `code` | Game code (Lua source or cart link) |
| 5 | `license` | License information |
| 6 | `like_count` | Number of likes/stars |
| 7 | `description` | Game description |
| 8 | `top_5_comments` | Top 5 comments (pipe-separated) |

## Task 3: RAG Database

Converts the scraped dataset into a queryable RAG database for PICO-8 code generation.

```bash
python task3_rag.py                                # Default test query
python task3_rag.py "Write a platformer game"      # Custom query
```

**Tech Stack:**
- **Vector Store:** ChromaDB (persistent, local)
- **Embeddings:** `all-MiniLM-L6-v2` (sentence-transformers)
- **Retrieval:** Cosine similarity, top-5 results
- **Output:** LLM-ready prompt with retrieved PICO-8 code context
